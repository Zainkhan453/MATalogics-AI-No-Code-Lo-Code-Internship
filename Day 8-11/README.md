## Folder convention

For each completed project, add a numbered folder containing:

- `README.md` - purpose, workflow logic, setup notes and test result
- `Workflow/` - exported Zapier workflow or configuration files
- `Screenshots/` - workflow and result evidence with private data removed
- links to live Interfaces, Forms or Chatbots when they are intentionally public

## Publishing the next project

From the repository root:

```bash
git pull --rebase origin main
git add "Day 8-11"
git commit -m "Days 8-11: complete Task 3 - AI Customer Support Bot"
git push origin main
```

Change the task number and title for each future project.

## Security and privacy

- Do not commit API keys, passwords, OAuth tokens or reusable credentials.
- Reconnect personal Zapier app connections after importing an exported workflow.
- Use sample records in screenshots and hide personal email addresses, phone numbers and customer data before publishing.
- Live Zapier links should only be committed when they are intended to be publicly accessible.
